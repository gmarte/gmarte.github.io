gmarte.com — email signature

The signature, in the same signal.

Two email-safe translations of the site’s design language. Email clients strip web fonts and stylesheets, so these use Georgia in place of Instrument Serif, Courier in place of IBM Plex Mono — tables and inline styles only.

Install in Gmail: press Copy signature below → Gmail → Settings (gear) → See all settings → General → Signature → Create new → paste (Ctrl/Cmd+V) → set it for new emails and replies → Save changes at the bottom.

S·01Credential chip — dark, with photo

The full brand statement: obsidian chip, serif name, mono roles, one red signal. The photo loads from gmarte.com, so it appears once the site is deployed. Best for external, first-contact email.
